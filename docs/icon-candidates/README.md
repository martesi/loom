# Loom icon candidates

Three single-app-icon concepts are provided for review. Each uses a rounded-square frame, following the macOS app-icon convention. `current-mark.svg` is an unchanged reference copy of `frontend/public/loom-mark.svg`; it remains the current mark and is not being replaced.

- **Current mark** — two offset rings suggest linked images and a loom shuttle.
- **Warp and shuttle** — contrasting shuttle crosses four visible warp threads. This is the strongest literal loom direction; the gold shuttle keeps the 16 px crossing distinct.
- **Frame and shuttle** — a simplified loom frame and vertical warp threads with a contrasting shuttle. Review as a secondary option; at 16 px the frame may read as a generic woven/grid mark rather than unmistakably as a loom.

Rendered review PNGs are generated by running `bun scripts/render-icon-candidates.ts` from `frontend/`. They are written to the git-ignored `.cache/icon-candidates/` directory and are not committed. `legibility-sheet.png` shows each candidate at native size and as nearest-neighbor enlargements (16 px at 4× and 32 px at 2×), so the pixel grid is visible. The frame-and-shuttle candidate is intentionally retained as a weaker option pending review.
